# JARVIS for Windows

[Visit the website](https://vexelbotrps-lgtm.github.io/jarvis-rudra/) · [Download the Windows ZIP](https://github.com/vexelbotrps-lgtm/jarvis-rudra/releases/download/v1.0/JARVIS-Windows.zip)

## Run Jarvis

1. Download `JARVIS-Windows.zip` from the GitHub Release.
2. Extract the **entire** `JARVIS` folder into Documents or Downloads. Keep `JARVIS.exe` and its companion files together.
3. Double-click `JARVIS.exe` on a 64-bit Windows 10 or 11 PC. Python is not required.
4. In first-run setup, enter your own Gemini API key **or** configure a supported local engine. Select a microphone and speakers in the app if needed.
5. Speak to Jarvis or type in the command field. For a phone microphone, open **Remote Control** in Jarvis and scan the QR code using Chrome on Android.

Your personal settings are created beside the executable after first run. Do not share the `config`, `memory`, or `logs` folders from a used installation. Internet features and optional integrations may need their own accounts or software. Startup errors appear in `logs/jarvis.log`.
